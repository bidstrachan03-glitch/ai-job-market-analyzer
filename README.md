# AI Job Market Skill Analyzer 🤖📊

## Overview
This project uses Python and NLP (spaCy) to analyze job postings and extract trending technical skills in the job market.

It helps identify what skills are most in demand based on real job data.

---

## Features
- Extracts skills from job descriptions using NLP
- Analyzes frequency of skills across job postings
- Visualizes top in-demand skills using graphs
- Cleans and processes raw job data

---

## Tech Stack
- Python
- Pandas
- spaCy (NLP)
- Matplotlib
- WordCloud (optional)

---

## How it works
1. Load job postings dataset
2. Use NLP to extract skill-related phrases
3. Count frequency of skills
4. Display results in terminal + graph

---

## Output Example
- Python: 67
- Java: 91
- AWS: 56

---

## Project Goal
To simulate how real-world job market analysis tools extract insights from unstructured job data.
